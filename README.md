# Lunar Engine
**Lunar Engine** is meant to be a recode of the rythm game [Friday Night Funkin'](https://ninja-muffin24.itch.io/funkin).

This engine is fully made in Lua using the LÖVE2D framework, Lunar Engine is meant to be used as more of a modding framework instead of a way of playing base game FNF.

# Contributing and Forks
You are free to take this engine's code to make your own forks, fixes, mods, contribute to it, and etc.

However if you end up making your own engine/fork using Lunar as a base **please consider crediting the original engine.**
